# launch/

Staged launch material for Milestone 19 (ROADMAP2): registry submissions,
posts, outreach, and the Z Fellows kit.

**The standing rule:** nothing in this directory is published by tooling or
automation. Every submission, post, and message goes out **under the
maintainer's identity, on his say-so** — these files exist so that saying
"go" costs minutes, not days. Facts inside (names, schemas, URLs) were
verified on the date noted in each file; re-check anything time-sensitive
before sending.
